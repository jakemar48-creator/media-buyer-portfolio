# Jacob Okparume — Media Buyer & Automation Portfolio

Single-page editorial portfolio. Open `index.html` directly, or serve the folder with any static server.

## What's real vs. placeholder

Everything on this site is sourced from:
- `Jacob_Okparume_Media_Buyer_Resume .pdf` (facts, dates, figures — nothing invented)
- Screenshots pasted in chat, matched by content to Growthpod, Chop Shop Media, and LandCurator
- Live screenshots captured directly from atlasgrowthcore.com, quiz.atlasgrowthcore.com, the LandCurator 1-Acre page, and the Mshel Homes page

There are no placeholders left to fill in — this is the real site.

## Editing

- Copy lives directly in `index.html`, organized by section comment-free but in document order: hero → $400K+ → ad account proof → GoHighLevel proof → 5 case studies → about → experience → contact.
- Images are in `assets/`, named by what they show (e.g. `meta-growthpod-jul2026.png`, `ghl-ai-lead-router.png`).
- Colors, type (Fraunces + Inter), and layout rules are in `style.css`.

## If you get new screenshots or want to swap assets

Match the filename pattern already in `assets/` and update the `src` in `index.html`, or just overwrite the existing file with the same name to keep everything else working.

## Known gaps (by design, not oversight)

- No dedicated "creative gallery" — the Meta Ads screenshots only show tiny thumbnail crops, not full-size creatives, so one wasn't fabricated. Add real creative exports to `assets/` and I can build that section properly.
- The GoHighLevel screenshots not explicitly labeled with a client name (the generic webhook demo, "0.5 Acres" sequence) were left out rather than guessed into a project they might not belong to.
